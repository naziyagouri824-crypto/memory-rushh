# 🧠 Memory Rush

> A fast-paced, interactive Memory Match Game built with **HTML, CSS & Vanilla JavaScript**.

Test your memory, build combos, use power-ups, and try to beat your best score. ⚡🎮

---

## 🎮 About the Game

**Memory Rush** is a visually engaging memory card game designed to make a classic matching game more exciting.

Flip the cards, find matching pairs, maintain your combo, and complete the board as quickly as possible.

The game includes multiple difficulty levels, different visual themes, power-ups, sound effects, achievements, and persistent best scores.

## 🎮 How to Play

1. Choose a **difficulty level**.
2. Select a **theme**.
3. Start the game.
4. Flip two cards at a time.
5. Find all matching pairs.
6. Build your combo by making consecutive matches.
7. Use **Peek** when you need help.
8. Use **Freeze Time** to stop the timer temporarily.
9. Finish the board with the best possible time and moves.
10. Try to beat your personal best! 🏆
